# Samjho (समझो)

Ek AI message decoder: SMS, WhatsApp forward, bill ya notice paste karo, aur use saral bhasha mein samjho, scam check ke saath.

## Files
- `samjho.html`: poora app (ek hi file, HTML + CSS + JS)

## Kaise chalega
Ye app Claude Artifacts ke andar chalta hai, kyunki AI call `window.claude.use("sample")` se hoti hai.
Browser mein seedha kholne par AI wala hissa kaam nahi karega, sirf on-device warning chips dikhenge.

Apne server par chalane ke liye `sample.json(...)` wali call ko apni LLM API call se badal do.

## Dhyan rakho
OTP, PIN, password ya poora card number kabhi paste mat karo.
